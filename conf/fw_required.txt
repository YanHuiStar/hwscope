# =============================================================================
# HwScope 固件推荐版本基线（conf/fw_required.txt）
# 供 modules/15_firmware.sh 判定 合规/落后/较新/未知。
#
# 格式（# 开头为注释行，解析时跳过）：
#   组件|型号模式|推荐版本|备注
#   - 组件    : GPU_VBIOS | BMC | NIC | NVSWITCH（大小写不敏感）
#   - 型号模式 : grep -E 子串/正则，匹配当前设备型号；留空 = 该组件所有设备
#   - 推荐版本 : 厂商验收手册推荐值；留空 = 仅记录当前版本，不做判定
#   - 备注    : 可选，写入报告"固件合规"段说明
#
# 版本比较规则：逐段比较（. - 空格 / 分隔），段内纯数字按数值、纯十六进制按
#   hex、混合按字典序；当前=推荐 → 合规；当前<推荐 → 落后；当前>推荐 → 较新
#   （较新不判落后，固件无需降级）。基线无匹配条目 → 判"未知"（仅记录，不 WARN）。
#
# ⚠️ 以下为示例/占位条目（FAKE 值），请按厂商验收手册替换为真实推荐版本后
#    取消注释。不录入任何条目 = 全部设备判"未知"，功能不受影响。
# =============================================================================
#GPU_VBIOS|||示例：GPU VBIOS 推荐版本（如 96.00.7C.00.01，按厂商手册填写）
#BMC|||示例：BMC 固件推荐版本（如 1.20.0，按厂商手册填写）
#NIC|ConnectX-6|20.31.1004|示例：ConnectX-6 推荐固件（按 NVIDIA 固件发布页填写）
#NIC|ConnectX-7|28.39.1014|示例：ConnectX-7 推荐固件
#NVSWITCH|||示例：NVSwitch 固件推荐版本（按厂商手册填写）
